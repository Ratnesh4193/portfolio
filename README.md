Modern engineering portfolio built with **Next.js 16** (App Router & Turbopack), **TypeScript**, **Tailwind CSS**, **shadcn/ui**, and **Magic UI**.

---

## ⚡ Tech Stack & Features

- **Framework**: Next.js 16 (React 19, Turbopack, App Router)
- **Styling**: Tailwind CSS & Lucide Icons
- **UI & Animations**: Magic UI (BlurFade, Dock navigation, Flickering Grid), shadcn/ui
- **Content**: Type-safe data configuration in [`src/data/resume.tsx`](./src/data/resume.tsx) + MDX blog powered by Content Collections
- **Themes**: Automatic Dark / Light mode with `next-themes`

---

## 🚀 Running Locally

1. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Production build**:
   ```bash
   npm run build
   npm run start
   ```
